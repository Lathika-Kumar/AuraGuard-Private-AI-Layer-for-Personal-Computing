# Benchmarking Strategy

AuraGuard includes a future benchmark module for collecting the following measurements:

- model name
- runtime
- device
- CPU usage
- NPU usage when available
- memory usage
- model load time
- inference latency
- tokens/sec where applicable
- embedding latency
- document processing latency

This module is intentionally not used to make unsupported claims about Snapdragon acceleration without actual measurement.
