# AuraGuard — Core Innovations

## 1. Zero-Cloud Privacy Architecture with Grounded Source Attribution
Unlike cloud RAG architectures that send user documents to external vector databases and cloud inference endpoints, AuraGuard performs all indexing, embedding, similarity search, and generation locally on `127.0.0.1`. Every answer generated by AuraGuard provides transparent, verifiable source attribution detailing the exact document name, page number, and ReMind memory identifier retrieved.

## 2. ReMind: Explicitly Approved Personal Context Intelligence
Most commercial AI tools either maintain unmanageable chat history logs or opaque server-side user profiling. ReMind introduces **user-governed semantic memory**:
* **Explicit Approval Gating**: Candidate memories undergo privacy pre-scanning and require user confirmation before being stored.
* **Dual Indexing**: Combines high-dimensional vector search with structured SQLite metadata (category, importance, source, expiration).
* **Guaranteed Deletion**: Deletion immediately wipes the database row, purges FAISS vector mappings, and verifies zero-result retrieval in real-time.

## 3. Defense-in-Depth Multi-Checkpoint Privacy Engine
AuraGuard implements an active security boundary around the LLM:
* **Checkpoint 1 (Input Guard)**: Rejects user prompts and candidate memories containing high-entropy secrets (API keys, RSA private keys, passwords).
* **Checkpoint 2 (Context Filtering)**: Neutralizes indirect prompt injection attacks embedded inside ingested documents or notes before prompt synthesis.
* **Checkpoint 3 (Output Guard)**: Scans generated text to redact inadvertent PII exposure (emails, phone numbers, credentials).

## 4. Authenticated Local Storage (AES-256-GCM + Windows DPAPI)
AuraGuard recognizes that on-device AI requires robust security against physical and filesystem attacks:
* **Authenticated Encryption**: All chunk text and memories are encrypted with AES-256-GCM (256-bit key, 96-bit IV, 128-bit authentication tag).
* **Envelope Encrypted FAISS**: The FAISS vector index binary is envelope-encrypted on disk and loaded into memory only during runtime.
* **Windows DPAPI**: Master encryption keys are protected using Windows DPAPI (`CryptProtectData`), tying key security directly to the logged-in user credentials without storing plaintext keys in `.env` or configuration files.

## 5. Hardware-Aware AI Runtime & Snapdragon NPU Path
AuraGuard is architected specifically for modern NPU-equipped personal computers:
* **Dynamic Hardware Detection**: Intelligently identifies CPU architecture, available execution providers, and Snapdragon silicon.
* **Provider Abstraction**: Dynamically selects `QNNExecutionProvider` on Snapdragon X Series hardware and cleanly falls back to `CPUExecutionProvider` on standard x86 systems.
* **INT8 Quantization**: Dynamic INT8 quantization shrinks embedding model disk footprint by 74.7% while maintaining 0.9529 cosine similarity to FP32.
